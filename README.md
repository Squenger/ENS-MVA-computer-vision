# ENS MVA — Object Recognition & Computer Vision

Personal monorepo for the ENS MVA *Object Recognition and Computer Vision* course.

## Structure

- `TP1/` — Assignment 1 (instance-level recognition)
- `TP2/` — Assignment 2 (neural nets / CNN notebook)
- `TP3/` — Assignment 3 (`recvis26_a3`)
- `Final Project/` — course final project

## Notes

- Large artifacts (datasets, `.mat`, checkpoints `.pth`, `runs/`, `data/`) are **not** tracked (see `.gitignore`) because of GitHub size limits.
- The original course git metadata for `TP3/recvis26_a3` was left untouched and backed up outside this repo (see `GIT_NOTES.md`).
